# Controlei - Controle de Assinaturas

Aplicação web para gerenciar assinaturas e gastos mensais. Projeto acadêmico desenvolvido com **React**, **Firebase** e **Tailwind CSS**.

## 📋 Sobre

Sistema para controlar assinaturas de serviços (Netflix, Spotify, etc), permitindo:

- Cadastro e login de usuários
- Adicionar, visualizar e excluir assinaturas
- Calcular gasto mensal total
- Interface moderna

## 🛠️ Tecnologias

- **React** 19 - Interface
- **Vite** - Build
- **Tailwind CSS** - Estilização
- **Firebase** - Autenticação e Banco de dados
- **React Router** - Navegação
